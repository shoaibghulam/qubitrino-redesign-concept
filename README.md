# Qubitrino redesign concept

An unofficial redesign concept of qubitrino.ai, made by Shoaib Ghulam as a UI/UX test assignment. This is not an official Qubitrino website.

- [Landing page](landing.html)
- [Personal account, 7 sections](index.html)
- [Design system](design-system.html)
- [Printable report](report.html)

Stack: Tailwind CSS (CDN) and vanilla JS ES modules, with design tokens in `tokens.css`. There is no build step. Data comes from the fictional demo MT5 report supplied with the assignment.
